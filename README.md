# 🛒 Ecommerce Website

A full-stack e-commerce web application built with **React** for the frontend and a dedicated **backend API** for handling server-side functionality.

The project is divided into separate frontend and backend applications and is connected to a deployed backend for handling requests from the React application.

## 📌 Project Overview

This project is a full-stack e-commerce application developed to provide a complete online shopping experience.

The application consists of:

- A React-based frontend
- A separate backend application
- API communication between frontend and backend
- Cross-Origin Resource Sharing (CORS) configuration
- Deployment of the backend using Render

The frontend communicates with the backend through API requests to retrieve and manage application data.
